Source & installationMinesweeperHQ solver

Every recommended move needs a reason.

MinesweeperHQ Logic is a small JavaScript library and command-line tool for studying Minesweeper constraints. It reads visible numbers and flags; there is no hidden mine layout to inspect.

Try a visible board

Enter a row-major board as JSON. null is a hidden square, "F" is an assumed mine, and 0–8 are visible clues. mines is the optional total number of mines.

Press Analyze to see proven moves and their explanations.
Everything runs in your browser. Nothing entered here is sent to a server.

A zero clue and one remaining mine

The example is a one-row board: a visible zero followed by two hidden squares. The square next to the zero must be safe. Because one mine remains on the board, the far square must contain it. Returned indexes start at zero, so the result contains safe index 1 and mine index 2.

A genuine 50/50

{"width":3,"height":1,"cells":[null,1,null],"mines":1}

Both mine placements satisfy the only clue. Each hidden square has probability 0.5, and neither is a proven safe move. Change the input above to this example to see the difference.

Use the API

import { solve } from './logic.mjs';
const result = solve({
  width: 3, height: 1,
  cells: [0, null, null], mines: 1
});

The result includes contradiction, safe, mines, probabilities, exact, and solutions. Every probability entry includes an index, a value, and an explanation.

How it works

First, it subtracts flags from neighboring clues. If a constraint has zero mines left, all its hidden squares are safe; if its remaining mine count equals its hidden-square count, all are mines. It also subtracts a smaller hidden-square set from a containing set. Finally, it enumerates compatible assignments when at most 18 unresolved squares remain.

Know the limits

Flags are assumptions. A wrong flag can make conclusions wrong or produce a contradiction. Larger positions receive proven deductions only, with exact: false. No mine total means each compatible assignment receives equal weight. This educational tool does not implement the frontier decomposition used by the full site.

For a visual board editor and the production solver, open the MinesweeperHQ solver. To practice the shapes behind these deductions, use the MinesweeperHQ pattern exercises.
